# Study-tools: NUR 291 Exam 1 study site

A static study website built from the Exam 1 study guides, class notes, lecture slides, and the bioterrorism PowerPoint.

- Open `site/index.html` in a browser (works offline, no server needed), or host the repo on GitHub Pages (the root `index.html` redirects to `site/`).
- Features: chapter pages with color-coded callouts, tables, slide images, full-text search (press `/`), dark mode, flashcards from every practice question, a dosage calculator, and a "studied" tracker saved in your browser.
- Edit the text in `content/*.md`, then rebuild with `npm install && node tools/build.mjs`.
