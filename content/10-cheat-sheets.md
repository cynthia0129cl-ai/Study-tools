## Tumor markers and "signature" labs

| Marker / test | Cancer / disorder | Remember |
|---|---|---|
| **PSA** | Prostate (and BPH, prostatitis) | ≥4 ng/mL needs workup. High sensitivity, low specificity. Can't tell BPH from cancer |
| **CA-125** | Ovarian | Normal in 50% of early cases. Also rises with endometriosis, fibroids, cirrhosis, diverticulitis. Not a screening test |
| **AFP + hCG** | Testicular | Should fall after orchiectomy. If they don't, look for more tumor |
| **Bence Jones protein** (urine), **M protein** | Multiple myeloma | Light chains are toxic to the kidney. CRAB criteria |
| **Reed–Sternberg cells** | Hodgkin's lymphoma | Diagnosed by lymph node biopsy |
| **Philadelphia chromosome** | CML (and some B-ALL) | Chromosome 9;22 swap in >90% of CML |
| **JAK2 mutation** | Polycythemia vera | About 90%. ↑RBC, WBC, and platelets with a low EPO level |
| **↓Ferritin, ↑TIBC, ↓MCV** | Iron deficiency anemia | Microcytic and hypochromic |
| **↑MMA** (normal homocysteine) | B₁₂ deficiency | Macrocytic plus neuro signs |
| **↑Homocysteine** (normal MMA) | Folate deficiency | Macrocytic, no lasting neuro deficits |
| **↑PT/PTT, ↓fibrinogen, ↑D-dimer** | DIC | Clots everywhere, then bleeds everywhere |
| **↑Eosinophils** | Allergy (type I) | Normal 1–2%. Up to 12% with severe allergic rhinitis |
| **Heinz bodies, ↑retics** | G6PD deficiency | Hemolysis |

## Must-know numbers

| Number | Meaning |
|---|---|
| **ANC <1,500** | Neutropenia (infection risk) |
| **ANC ≤500** | Neutropenic precautions. Fever means IV antibiotics now |
| **Temp ≥100.4°F / 38°C** | Call the provider (chemo, neutropenia) |
| **Platelets <150,000** | Thrombocytopenia |
| **<100,000 / <50,000** | Start bleeding precautions / spontaneous bleeding possible, no sex |
| **<20,000** | Spontaneous bleeding. Platelets usually transfused |
| **<5,000** | Fatal CNS or GI bleed possible |
| **SpO₂ <90%** | Significant oxygenation problem. Goal ≥90% |
| **Hct <45%** | PV phlebotomy goal |
| **Ca >11 / >11.5 mg/dL** | Hypercalcemia (lymphoma / myeloma CRAB) |
| **INR 2–3 / 2.5–3.5** | Warfarin goal / mechanical valve |
| **Acetaminophen 3,000 mg** | 24-hour max (1,000 mg per dose) |
| **Gleason 2–10** | Two grades (1–5) added. Higher is worse |
| **RBC life 120 days** | Sickle cell RBC 15–20 days. Platelets 7–10 days |

## Precautions side by side

| Neutropenic (↓WBC) | Bleeding (↓platelets) |
|---|---|
| Hand hygiene, private room | Soft toothbrush, no floss |
| Avoid crowds, sick people, small kids, pets. Mask outside | Electric razor, shoes on, clutter-free |
| No fresh flowers or plants, no standing water | Stool softener, don't blow your nose |
| Wash produce. No raspberries or blackberries | No IM injections. Minimal BP cuff pressure |
| Daily temperature. Fever ≥100.4°F means call or go now | Pressure or ice ≥5 minutes for cuts |
| **BOTH:** no rectal temperatures, suppositories, or enemas | |

## Painless vs painful masses

| | |
|---|---|
| **Painless** | Breast cancer lump (typically), lymphoma nodes, testicular cancer, malignant lymph nodes (less tender than infected ones) |
| **Pain is the clue** | Myeloma (back and bone), leukemia (bone), sickle cell crisis, prostate cancer (late), spinal cord compression (back pain first) |

## Lab values from class (NUR 291)
*Need to know lab numbers for exams (electrolytes, CBC).*

### Electrolytes

| Electrolyte | Normal | Too low / too high | Memory trick |
|---|---|---|---|
| **Sodium (Na⁺)** | 135–145 mEq/L | <135 hyponatremia · >145 hypernatremia | Commit to memory |
| **Potassium (K⁺)** | 3.5–5.0 mEq/L | <3.5 hypokalemia · >5.0 hyperkalemia | A bunch of bananas has 3–5, and you want them half ripe (.5): 3.5–5.0 |
| **Phosphorus (P)** | 2.5–4.5 mg/dL | <2.5 hypophosphatemia · >4.5 hyperphosphatemia | "PHOR" = 4, "us" = 2 (me + you); don't forget the .5 |
| **Calcium (Ca²⁺)** | 9–11 mg/dL | <9 hypocalcemia · >11 hypercalcemia | Call 911 |
| **Magnesium (Mg²⁺)** | 1.5–2.5 mg/dL | <1.5 hypomagnesemia · >2.5 hypermagnesemia | MAGnifying glass: 1.5–2.5, a little bigger than normal |
| **Chloride (Cl⁻)** | 95–105 mEq/L | <95 hypochloremia · >105 hyperchloremia | A chlorinated pool on a 95–105°F day |

**Where these show up in this guide:**
- **Calcium:** hypercalcemia from bone mets, lymphoma, and myeloma (CRAB >11.5), DiGeorge hypocalcemia (tetany), tumor lysis hypocalcemia.
- **Potassium and phosphorus:** tumor lysis syndrome raises both (peaked T waves, heart block).
- **Sodium:** SIADH from brain and lung cancer causes dilutional hyponatremia (confusion, seizures).

### Complete blood count (class) ★

| Lab | Memory hook | Normal (class) |
|---|---|---|
| **WBC** | Wanna Buy a Car | 5,000–10,000/mcL |
| **RBC** | Blood | 4.5–5.5 million/mcL |
| **Hemoglobin** | Oxygen | 12–18 g/dL |
| **Hematocrit** | Hemato-"crisis" | 37–50% |
| **Platelets** | China plates | 150K–400K/mcL |

:::note Class vs book
Your class CBC sheet and the textbook (Table 33.7) use slightly different ranges.
- **WBC:** class 5,000–10,000 vs book 4,500–11,100
- **Platelets:** class 150K–400K vs book 150K–450K
- **Hgb:** class 12–18 vs book F 11.7–15.5, M 14–17.3
- **Hct:** class 37–50% vs book F 36–48%, M 42–52%
- **RBC:** class 4.5–5.5 million vs book F 4.01–5.51, M 4.51–6.01

Exam questions usually use values clearly outside both ranges, but ask your instructor which set the exam uses.
:::
