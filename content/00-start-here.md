## One-page cram sheet ★
*If you only read one page.*

### Oncology
- Cancer cells: **no apoptosis, no contact inhibition.**
- **Carcinogens = #1 risk factor;** BRCA1/2 → breast/ovarian.
- **TNM:** T size · N nodes · M mets. **M1 = not local.**
- Breast sizes: ≤2 · 2–5 · >5 cm.
- **CAUTION >2 weeks → evaluate.**
- **Biopsy = only definitive diagnosis.**
- **Neo = before · Adjuvant = after.**
- **Chemo + fever ≥100.4°F = call now.**
- **Palliative = from diagnosis; hospice = ≤6 months, no curative tx.**
- **Lung:** smoking 90%; NSCLC 85% good; SCLC 15% bad; **never clamp chest tube.**
- **Breast:** age #1 risk; frozen shoulder; lumpectomy → radiation; ER+ → tamoxifen, stop OCPs.
- **Ovarian:** bloating, early satiety, no screening, CA-125.
- **Uterine:** unopposed estrogen + obesity; vaginal bleeding.
- **Cervical:** HPV; Pap at 21, every 3 years; postcoital bleeding.
- **Prostate:** PSA ≥4; Gleason max 10; impotence + incontinence post-op; brachytherapy: thicker PPE, no sex 2 weeks.
- **Testicular:** age 33, cryptorchidism, painless mass, AFP/hCG, sperm bank.
- **Male breast:** BRCA2, mastectomy, hormone tx only if receptor +.

### Heme and immune
- **Left shift** = immature neutrophils (bands) = active infection.
- **Neutrophils:** bacteria/fungi, first to arrive, 6 hours.
- **Intrinsic → PTT (heparin) · Extrinsic → PT/INR (warfarin).**
- **Ferritin = stores · transferrin = transport · TIBC ↑ in IDA** = low O₂ sat.
- **IDA diet:** red meat, spinach, beans + vitamin C, no dairy; iron on empty stomach.
- **Anemia:** BP ↓, HR ↑, RR ↑; low albumin = nutrition.
- **PV:** thick blood → hydrate, phlebotomy; stroke/DVT risk.
- **Platelets <50k:** no IM, no rectal, soft brush; **Bactrim #1 drug cause.**
- **Leukemia:** immature WBCs → infection, anemia, bleeding; benzene, Down syndrome.
- **Neutropenic:** no plants, no humidifiers, reverse isolation (you wear PPE).
- **Lymphoma:** painless nodes + B symptoms; Reed–Sternberg; SVC syndrome.
- **Myeloma:** CRAB, hypercalcemia (tingling), push fluids, bisphosphonates, ambulate.
- **IgG** crosses placenta · **IgM** first · **IgE** allergy · **IgA** secretions.
- **Humoral** = B cells/antibodies · **Cellular** = T cells.
- **XLA:** boys, 6 months, BTK, IVIG every 3–4 weeks · **DiGeorge:** CATCH, ↓Ca, FISH.
- **Anaphylaxis:** stop drug → IM epi → O₂; don't drop BP.
- **Only NS with blood · O donor · AB recipient.**
- **Latex ↔ banana, avocado, kiwi, chestnut.**
